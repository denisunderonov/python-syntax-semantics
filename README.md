# Python OOP Analytics

Учебный проект по применению объектно-ориентированного программирования в Python в рамках School 21.

В проекте на примере анализа результатов подбрасывания монеты разобраны основные принципы ООП и организация Python-проекта.

## Что было изучено

* классы и методы;
* конструктор `__init__`;
* вложенные классы;
* наследование;
* работа с конфигурацией;
* разделение кода на модули;
* обработка исключений;
* сохранение результатов в файлы;
* логирование;
* работа с HTTP-запросами.

## Практика

В проекте реализован небольшой аналитический модуль, который:

* читает исходные данные из CSV;
* рассчитывает количество и долю орлов и решек;
* строит случайные прогнозы;
* использует наследование для расширения функциональности;
* формирует текстовый отчёт;
* сохраняет результаты;
* записывает события и ошибки в лог.
